
# Project Requirements

## Problem Statement
Students may find it difficult to organize academic
tasks and remember assignment deadlines.

## Functional Requirements
1. Users can add academic tasks.
2. Users can view all tasks.
3. Users can mark tasks as completed.
4. Users can view pending tasks.

## Non-Functional Requirements
1. The application should be easy to use.
2. The code should be maintainable.
3. The application should respond quickly.

## Project Scope
The first version will be a simple Python application.
Database and web features may be added later.
